# SiteQuote

SiteQuote is an Android/iOS contractor CRM built with Expo, React Native and Supabase. Each account owns its leads, projects, tasks, private photos, USD estimates, immutable quote versions and reminders.

**Phases 0–5D are coding implemented. Release verification is incomplete.** Current results and release blockers are in [FINAL_AUDIT.md](FINAL_AUDIT.md).

The mobile app requires a configured HTTPS Supabase project. Browser support is not implemented; use Android/iOS development builds for native acceptance.
